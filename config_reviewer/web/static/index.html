How it works

  1. Input. Upload files, a folder, or paste a config. Files are reviewed in memory and never stored.
  2. Detect. Each file's type is decided from its name, then by sniffing YAML content (e.g. apiVersion + kind means Kubernetes).
  3. Rule engine. 74 deterministic checks across 6 file types, plus a secret scanner that runs on every file. Offline, instant and free.
  4. AI review (optional). Claude receives the file with line numbers and the rule findings, and is asked only for new issues. Its answer must match a strict JSON schema, so AI findings look exactly like rule findings.
  5. Score. Start at 100; subtract 25 per critical, 10 per high, 5 per medium and 2 per low finding. Grade A ≥ 90, B ≥ 75, C ≥ 60, D ≥ 40, else F.
  6. Report. View findings here or download JSON, Markdown or SARIF (for GitHub Code Scanning).

Command line

python -m config_reviewer examples/insecure
python -m config_reviewer . -f sarif -o results.sarif --fail-on high
